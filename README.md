# הצפנת סיסמאות

דף אחד: מזינים סיסמה וקוד הצפנה, מקבלים מחרוזת מוצפנת. מי שיש לו את
קוד ההצפנה מדביק את המחרוזת ומקבל את הסיסמה חזרה.

## ההצפנה

| | |
|---|---|
| אלגוריתם | `AES-256-GCM` — הצפנה מאומתת |
| גזירת מפתח | `PBKDF2-SHA256`, **600,000 סיבובים**, מלח אקראי 16 בתים |
| IV | 12 בתים אקראיים, חדשים בכל הצפנה |
| פלט | base64 של `גרסה(1) + מלח(16) + IV(12) + מוצפן+חתימה` |

הכול דרך ה-Web Crypto המובנה בדפדפן. **אין שום ספרייה חיצונית** — לא
צריך לסמוך על קוד של אף אחד מלבד הדפדפן עצמו.

GCM הוא מאומת, כלומר הוא מזהה שינוי במחרוזת. שינוי של ביט אחד בכל מקום
— בטקסט המוצפן, ב-IV או במלח — גורם לפענוח להיכשל במקום להחזיר זבל.

## למה אי אפשר לדלוף מכאן

הדף **פורסם לאינטרנט** ולכן הושקעה מחשבה בזה:

- אין `fetch`, אין `XMLHttpRequest`, אין טופס, ואין שום משאב חיצוני
- יש כלל `Content-Security-Policy` עם `connect-src 'none'` ו-
  `form-action 'none'`, שחוסם כל יציאה לרשת **ברמת הדפדפן**. גם אם
  מישהו היה מצליח להזריק קוד לדף, הוא לא יוכל לשלוח כלום החוצה.
- אין `localStorage`, אין `sessionStorage`, אין עוגיות. סגרת לשונית,
  הכול נעלם.

אפשר לנתק את האינטרנט אחרי שהדף נטען, והכול ימשיך לעבוד. זו הבדיקה
הפשוטה ביותר שהוא באמת מקומי.

## מה נבדק

הורצו **פונקציות ההצפנה מתוך הדף עצמו**, לא עותק שלהן:

| | |
|---|---|
| הלוך ושוב | כל סימני הפיסוק, גדולות וקטנות, 128 תווים, עברית, אמוג'י, 5000 תווים ✓ |
| קוד הצפנה | סימנים, עברית, אמוג'י, רווחים, 200 תווים ✓ |
| מפתח שגוי | נדחה — כולל הבדל של תו אחד או של אות גדולה ✓ |
| שינוי במחרוזת | נתפס בטקסט המוצפן, ב-IV ובמלח ✓ |
| כל הצפנה שונה | אותו קלט נותן פלט אחר בכל פעם ✓ |
| קלט פגום | לא-base64, ריק, חתוך, גרסה זרה — הודעה ברורה ולא קריסה ✓ |
| זמן גזירה | 600 אלף סיבובים ≈ 270ms במחשב |

**באג שתוקן:** מד החוזק פסל סיסמה חזקה בת 128 תווים, כי היא הכילה
"123456" בתוך רצף ספרות. עכשיו התאמה מלאה פוסלת תמיד, אבל הכלה פוסלת
רק בסיסמה קצרה מ-16 תווים.

## המגבלה האמיתית

חוזק ההגנה תלוי כמעט כולו בקוד ההצפנה. AES-256 לא נשבר, אבל קוד הצפנה
חלש אפשר לנחש. לכן יש בדף מד חוזק שמחשב אנטרופיה בזמן אמת.

ואם תאבד את קוד ההצפנה — אין שחזור. אין דלת אחורית, וזה מה שהופך
את זה לבטוח.
